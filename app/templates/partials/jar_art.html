{# A jar, drawn: labelled glass with the starter's own state showing in it. Expects `jar`. Optionally: rise_pct the last measured rise, which sets the level in the glass art_class a size class (jar-art-lg, jar-art-shelf) with_label false to leave the taped label off dusty true for a jar that has been put away a while mood where the jar is between feeds, as the ribbon's band name (rising, peak, ok, past, hungry): a starter at its peak stands domed and foaming, a hungry one has slumped and left a tide line on the glass Inline SVG so it themes with the page and costs no request. Unmeasured jars sit where their state puts them, so the picture is never silent. The tape starts at y 77, so even a flat jar shows some starter above it. -#} {%- if measured -%} {%- set level = [[rise_pct, 0] | max, 150] | min -%} {%- set fill_top = 70 - (level / 150 * 38) -%} {%- else -%} {%- set fill_top = {"active": 52, "fridge": 62, "dormant": 68, "dried": 68}[state] -%} {%- endif -%} {#- The mood is the model's reading of this minute, where a measurement may be a day old: so it only ever overrules the drawing in the direction it is sure of. An unmeasured jar stands where its mood puts it; a measured one keeps its level, unless the jar has since gone over or gone hungry, in which case it is drawn fallen however high it once stood. -#} {%- set mood = mood if (mood is defined and mood and state == "active") else none -%} {%- set mood_top = {"rising": 58, "peak": 42, "ok": 48, "past": 58, "hungry": 65}.get(mood) -%} {%- set was_top = fill_top -%} {%- if mood_top is not none -%} {%- if not measured -%}{% set fill_top = mood_top %} {%- elif mood in ("past", "hungry") -%}{% set fill_top = [fill_top, mood_top] | max %}{% endif -%} {%- endif -%} {%- set fallen = mood in ("past", "hungry") -%} {%- set flat = mood == "hungry" -%} {%- set lively = (not fallen) and ((rise_pct > 40) if measured else (state == "active")) -%} {%- set dome_ry = 6.4 if mood == "peak" else (1 if flat else (4.2 if lively else 1.8)) -%} {%- set body = jar_body_path -%} {%- if jar.is_control -%} {%- set caption = "control" -%} {%- else -%} {%- set caption = jar.flour_type or jar.culture_name or jar.origin.value -%} {%- endif -%} {#- The tape is drawn; the writing on it is HTML laid over the drawing, so it can wrap, size itself to the jar it is on and never be cut by a character count. `--n` is the longest line in characters: the stylesheet turns that into a size with a container query unit, so the same markup fits a 58px jar and a 140px one.
